## Публикация

```powershell
cd C:\Users\User\privacy-policy
git add -A
git commit -m "Update privacy policy"
git push
```

Pages настроен на ветку `main`, каталог `/`. Изменения появляются на сайте
через 1–2 минуты после пуша.

## Когда нужно править текст

Политика описывает текущее состояние игры. Обновлять её нужно, если вы:

- добавите аналитику (Firebase, Unity Analytics, GameAnalytics) — разделы 2.2 и 3;
- включите внутриигровые покупки или подписку — разделы 3 и 4;
- добавите облачные сохранения или вход в аккаунт — разделы 2.1 и 2.3;
- начнёте показывать рекламу через другие сети или медиацию — раздел 2.4;
- добавите разрешения (камера, микрофон, геолокация) — раздел 2.3;
- измените срок хранения обращений — раздел 4.

После правок обновите дату «Last updated» в начале `index.html`.

## Ссылка для Google Play

Play Console → App content → Privacy policy → указать URL сайта.

Дополнительно в Play Console → Data safety нужно отметить: собирается
рекламный идентификатор и IP-адрес, данные передаются третьей стороне (Google),
данные шифруются при передаче, удаление данных — через сброс рекламного ID.
